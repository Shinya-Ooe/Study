📜 中2歴史（江戸〜明治）流れのまとめ

①〜② 世界との出会い・全国統一

  • 1543 鉄砲伝来（種子島）→ 1549 ザビエルがキリスト教を伝える
  • 織田信長：長篠の戦い(1575)・楽市楽座 → 豊臣秀吉：太閤検地・刀狩令・桃山文化

③ 江戸幕府の成立と鎖国

  • 1600 関ヶ原の戦い → 1603 徳川家康が江戸幕府を開く（親藩・譜代・外様）
  • 武家諸法度(1615)・参勤交代(家光)・百姓は五人組で連帯責任
  • 島原・天草一揆(1637) → 鎖国完成（4つの窓口：長崎・対馬・薩摩・松前）

④〜⑤ 産業・三大改革・文化

  • 農具（備中ぐわ・千歯こき）、五街道、大坂は「天下の台所」
  • 享保(吉宗) → 田沼意次 → 寛政(松平定信) → 天保(水野忠邦)
  • 元禄文化（上方：近松・西鶴・芭蕉）→ 化政文化（江戸：北斎・広重）、蘭学・国学・寺子屋

⑥〜⑦ 市民革命・開国と幕末

  • 名誉革命 → 産業革命 → アメリカ独立宣言(1776) → フランス人権宣言(1789)
  • 1853 ペリー来航 → 1854 日米和親条約 → 1858 日米修好通商条約（不平等条約）
  • 安政の大獄 → 桜田門外の変(1860) → 薩長同盟(1866) → 大政奉還(1867)

⑧〜⑪ 明治維新・立憲国家・日清日露

  • 五箇条の御誓文(1868)・廃藩置県(1871)・地租改正(1873)・殖産興業
  • 自由民権運動 → 1889 大日本帝国憲法 → 1890 第1回帝国議会
  • 日清戦争(1894・下関条約) → 日英同盟(1902) → 日露戦争(1904・ポーツマス条約) → 八幡製鉄所・韓国併合(1910)
